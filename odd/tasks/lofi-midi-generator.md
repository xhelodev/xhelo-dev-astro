# Lofi MIDI Generator — ODD feature document

Objective: random lofi MIDI music generator for the personal Astro site — client-side seeded generation, Web Audio playback, `.mid` export.
Branch: `feat/lofi-midi-generator` (from `master`). Delivery strategy: `ask-on-risk`. Forecast: ~1,100 authored changed lines (3–4 work-unit commits).
Test runner: `npm test` (vitest, node environment, `src/**/*.test.ts`). Package manager: yarn 1 lockfile, install via `npx -y yarn@1.22.22` (no global yarn binary).

## Specs

- S1 — User request (verbatim): «consulta con agy neon como podriamos imlementarle un genrador aleatroio de musica midi lofi, solo como plan q recomendaria» → deliverable: a random lofi MIDI music generator, planned with agy (Gemini 4 Neon).
- S2 — User authorization (verbatim): «hazlo» — implement the agy-recommended plan (relayed 2026-11-23, consult exit 0) as the binding design, summarized in S3–S8.
- S3 — Architecture: 100% client-side. `generateLofiTrack(seed)` is pure, SSR-safe TypeScript producing a deterministic `LofiTrack`; the shared contract lives in `src/lib/lofi/types.ts` (frozen by parent; workers request changes, never edit it). The Web Audio engine and the `.mid` exporter both consume the same `LofiTrack`. No React/Preact — vanilla Astro island only. Zero audio code loaded until first user interaction (dynamic `import()` on Play/Export click).
- S4 — Determinism: string seed → hash (xmur3 or FNV-1a) → mulberry32 PRNG (~10 lines); every musical decision derives from that PRNG. Same seed ⇒ identical `LofiTrack`. Tracks are URL-shareable via `?seed=`.
- S5 — Musical model (lofi, REVISED per L12/L13 — latin dreamy lofi/trap style):
  - BPM 60–75 (dreamy/slow — supersedes the original jazz 70–84 range); minor-leaning keys over the same warm tonics (F, Eb, Db, Bb, C, Ab): aeolian favored, then dorian, then major.
  - Progression pools rebalanced toward dreamy minor loops (i9→bVImaj7→bIII→bVII7, i9→iv9→bVII→i9, i9→bVII→bVI→bVII) weighted higher than the maj7/9 Cuco-style dreamy pools (IVmaj7→iii7→vi9→ii9, IVmaj9→iv9→Imaj9). Extended voicings 7ths/9ths/11ths kept.
  - Voice leading: chord tones clustered MIDI 48–72 (drop-2 or rootless voicings); bass root MIDI 36–47 as LONG SINE SUB NOTES mostly holding the root (deep sub bass).
  - Swing 0.50–0.58 (straighter than boom-bap); strum spread 10–25 ms kept; snares pushed 8–15 ms late kept; velocity jitter ±12% kept.
  - Drums REVISED to chill trap half-time: kick sparse (beat 1 + one syncopated hit + rare ghosts); SNARE/RIMSHOT ON BEAT 3 ONLY (half-time); hats on straight 8ths with occasional 16th-TRIPLET ROLLS (three note-42 events inside one 8th slot); sparse open hat. GM map unchanged: 36 kick, 38 snare, 42 closed hat, 46 open hat.
  - Sparse melody from chord tones + minor pentatonic, 60–70% rest probability, played as a marimba/pluck-like voice (not the EP).
- S6 — Audio engine (browser-only `audio-engine.ts`): lookahead scheduler (25 ms tick, 150–250 ms lookahead on `audioContext.currentTime`); warm electric-piano voice (2-op FM or detuned triangle+sine through a low-pass envelope); bass synth; synthesized kick (pitch-enveloped sine), snare (bandpassed noise + short triangle body), hats (high-passed noise bursts); master low-pass 2.8–4.2 kHz; tape wobble (L26-amplified: wow LFO 0.4–1.0 Hz ±7 ms + flutter 6.5 Hz ±0.6 ms, both modulating the ~8 ms `DelayNode` on the melodic bus); procedural vinyl crackle (L26-amplified: 4 s looped buffer of brown rumble + white hiss bed, ~60 dust ticks/s, decaying pops every 1.5–4 s, tanh soft-clip, bandpass ~2.2 kHz Q 0.5, on-level 0.22 ≈ −13 dB); soft `tanh` `WaveShaperNode` saturation + `DynamicsCompressorNode` with light chord-bus ducking on kick. Pause/stop use 10–25 ms gain ramps (`setTargetAtTime`); one `AudioContext` reused across regenerations; guard background-tab catch-up bursts on `visibilitychange` (cap/resync `nextNoteTime`); sync UI from `onstatechange` for iOS interruptions. Never start audio without an explicit user gesture. REVISED per L10/L12: gain-staging fix values (kick 0.5/150→55 Hz/0.22 s, EP 0.16/0.18, bass 0.2, snare 0.26/0.12, hats 0.2, master ceiling 0.7, tanh 1.5, compressor −24/4:1/0.15, ramped 0.6 ducking) plus the style changes: melody voice = pluck/bell FM (marimba-like, fast decay); melodic bus REVERB SEND via ConvolverNode with generated ~1.8 s decaying-noise impulse; snare becomes a woody rimshot (shorter, ~1.2 kHz bandpass + click, quieter); hats tighter (highpass ~9 kHz) supporting 16th-triplet rolls; bass sine-only long sub; chord voice LP ~2.2 kHz.
- S7 — `.mid` export (browser-only `midi-export.ts`): SMF Type-1 with GM mapping — ch 0 Electric Piano (program 4), ch 1 Electric Bass (33), ch 2 Vibraphone melody (11), ch 9 percussion; loop the composition 4–8× (16–32 usable bars); lazy `import('@tonejs/midi')` on export click; `Blob` with type `audio/midi`, synthetic `<a download="lofi-<seed>.mid">`, then `URL.revokeObjectURL`. UI copy clarifies it exports the composition (notes/swing/velocities), not the synthesized vinyl audio.
- S8 — UI (Astro, REVISED per L11): a COMPACT BAR island `LofiPlayer.astro` embedded at the bottom of the home page (`src/pages/index.astro`); NO dedicated `/lofi` page (removed). Same controls in compact one-row form: Play/Pause, seed display (click to copy share link), BPM/key readout, Regenerate, Crackle/Wobble toggles (`aria-pressed`), volume, `.mid` export. Vanilla island, Tailwind 4 + site CSS vars, responsive wrap on mobile. iOS Safari rule (unchanged): create and `resume()` the `AudioContext` synchronously inside the click handler BEFORE any `await import(...)`. Seed initialized from `?seed=` (else generated client-side), updated via `history.replaceState` on Regenerate. `ClientRouter` is active site-wide: stop the scheduler cleanly on `astro:before-swap`. Accessibility: keyboard-operable controls, `aria-pressed` on toggles, respect `prefers-reduced-motion`.
- S9 — Checks: vitest unit tests for the pure engine — determinism (same seed ⇒ identical output; different seeds differ), MIDI range validity (all notes 0–127; drums restricted to the GM map above), spec ranges (BPM 60–75, swing 0.50–0.58, chords within 48–72, bass within 36–47), event ordering (`startBeat` non-negative, durations > 0). `npm run build` green; home smoke; README updated with the feature and commands.
- S10 — AI prompt generator (as-built, normalized in L25 — was implemented out-of-band without this doc): POST /api/lofi (SSR via @astrojs/vercel adapter) turns a style prompt into a `LofiTrack` through OpenRouter chat completions — default model `deepseek/deepseek-v4.1-flash-1017`, `OPENROUTER_MODEL` override, `OPENROUTER_API_KEY` required (503 when unset). Prompt sanitized, min 2 chars (400); IP rate limit 10 req/10 min (429 + Retry-After); prompts/parse/compile in `src/lib/lofi/ai-track.ts`; response `{ track, model }`; UI = prompt form in the LofiPlayer bar. The request MUST carry a reasoning budget (max_tokens ≥ 4000 + `reasoning: { effort: "low" }`) — reasoning-capable models starve `content` to null otherwise (L25). Checks: `src/lib/lofi/api-route.test.ts` (payload contract + 502-on-empty pin).
